# MuleSoft Internal API Marketplace

A full-stack MuleSoft project simulating an internal Anypoint Exchange platform.

## Features

- Publish APIs (`POST /apis`)
- List APIs (`GET /apis`)
- Subscribe to APIs (`POST /subscriptions`)
- View subscriptions (`GET /subscriptions`)
- SLA tiers: Bronze, Silver, Gold

## Technologies

- Mule 4.5
- RAML 1.0
- Object Store v2
